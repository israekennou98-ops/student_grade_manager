Student Grade Manager

A beginner Python project to manage student grades and calculate averages.

Features

- Enter student names and grades.
- Validate grades between 0 and 20.
- Calculate each student's average.
- Assign a result based on the average.
- Calculate the class average.
- Display the highest and lowest averages.
- Identify the top student.
- Count passed and failed students.

Technologies

- Python 3

How to Run

1. Install Python 3.
2. Download "student_grade_manager.py".
3. Open a terminal in the file's folder.
4. Run:

python student_grade_manager.py
